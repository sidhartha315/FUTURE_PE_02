# Future Interns — Prompt Engineering Task 2

## Project Title

AI Content Marketing Using UGC-Style Ads for Glow Studio

## Overview

This project explores how structured prompt engineering can help generate advertising content for a local beauty salon.

Glow Studio is a beauty salon concept based in Hyderabad, Telangana. The project uses Google Gemini to develop marketing ideas, advertising hooks, short-form video scripts, and platform-specific promotional content.

## Business Profile

* **Business:** Glow Studio
* **Industry:** Beauty and personal care
* **Location:** Hyderabad, Telangana
* **Services:** Hair styling, professional makeup, skincare and facials, and nail care
* **AI tool:** Google Gemini

## Project Objectives

* Analyze the target audience and business needs.
* Generate attention-grabbing advertising hooks.
* Create short-form UGC-style video advertising scripts.
* Adapt promotional content for different social media platforms.
* Use structured prompts to improve consistency and relevance.

## Prompt Engineering Approach

The prompts define the AI's role, business context, task, constraints, and expected output format. This structure helps produce more consistent and business-relevant advertising content.

## Responsible AI Practices

* Promotional concepts are not presented as genuine customer testimonials.
* Unsupported claims, invented prices, and unverified offers are avoided.
* AI-generated content should be reviewed before publication.
* Business details should be verified before using the content commercially.
